# Carsharing analytics

Локальное PHP-приложение для анализа каталога и состояний автомобилей каршеринга.

Возможности:

- каталог: вид транспорта → марка → модель;
- ручная диагностика гостевых API-выдач без записи данных;
- ручной сбор снимка свободных и занятых автомобилей;
- хранение текущего состояния и полной истории наблюдений;
- фиксация переходов между статусами;
- рейтинг автомобилей и моделей по числу подтверждённых аренд и возвратов.

## Требования

- PHP 7.0 или новее с расширениями PDO MySQL, cURL и mbstring;
- MySQL 5.6 или новее;
- локальный веб-сервер, например OpenServer.

## Установка

1. Разместите файлы в каталоге сайта OpenServer.
2. Импортируйте `database_dump.sql` в MySQL. Дамп создаёт базу `voron` и содержит текущий каталог и первый снимок состояний.
3. По умолчанию приложение подключается к `127.0.0.1:3306`, база `voron`, пользователь `root`, пустой пароль.
4. При других настройках задайте переменные окружения:
   - `VORON_DB_HOST`
   - `VORON_DB_PORT`
   - `VORON_DB_NAME`
   - `VORON_DB_USER`
   - `VORON_DB_PASS`

## Страницы

- `index.php` — каталог транспорта;
- `diagnostic.php` — ручная проверка одного API-запроса без записи;
- `collector.php` — два запроса и запись снимка в базу;
- `analytics.php` — текущие показатели и рейтинг аренды.

Первое наблюдение автомобиля является исходной точкой и не считается заказом. Событие аренды создаётся только после реального перехода между двумя снимками.

Автоматический запуск сборщика в проекте не настроен.

## Структура базы

- `vehicle_types`, `brands`, `models` и таблицы связей — каталог;
- `vehicles` — конкретные автомобили и текущее состояние;
- `collector_runs` — журнал запусков;
- `vehicle_status_history` — снимки состояний;
- `vehicle_status_events` — только изменения состояния;
- `statuses` — справочник нормализованных статусов.

`schema.sql` предназначен для чистой установки. Файлы `migration_*.sql` документируют последовательные изменения уже существующей базы.
